## گیت هاب چیست؟

پلتفرمی است که در آن توسعه دهنگان وب از سراسر جهان در آن گرد هم آمده و با یکدیگر ارتباط و همکاری دارند. در گیت هاب شما به عنوان توسعه دهنده وب می‌توانید پروژه‌های خود را با همکارانتان یا هر فرد دیگری که مایل باشید به اشتراک بگذارید و به صورت مشترک روی یک پروژه کار کنید. به این ترتیب به سادگی می‌توانید نسخه‌های قبلی یک نرم افزار را ارتقا دهید بدون این که تغییر یا اختلالی در نسخه‌های فعلی ایجاد شود

## گیت چیست؟

گیت معروف‌ترین و محبوب‌ترین سیستم کنترل ورژن در جهان است که اکثر برنامه‌نویسان از آن برای مدیریت پروژه‌هایشان استفاده می‌کنند
گیت با امکانات فراوانش برای حل تمامی این مشکلات به‌وجود آمده است و به‌رایگان دراختیار شما قرار دارد. به‌طور‌کلی، گیت برای مدیریت سورس پروژه و ثبت و ایجاد تاریخچه تغییرات و انجام پروژه‌های گروهی استفاده می‌شود

## تفاوت گیت و گیت هاب چیست؟

گیت سیستم کنترل نسخه‌ای است که برای مدیریت کدهای پروژه استفاده می‌شود، اما گیت هاب پلتفرمی است که برای میزبانی و به اشتراک‌گذاری کدهای پروژه به کار می‌رود
